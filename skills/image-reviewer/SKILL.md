Invoke `image-reviewer` after an image has been generated by `n8n-builder` to review it against the CONCEPT BLUEPRINT. Pass it the generated image file path, the original CONCEPT BLUEPRINT, and the prompt that was sent. The agent inspects the image through four lenses — blueprint adherence (subject, style, composition, lighting, mood, palette, negative space), composition and visual quality, style consistency, and technical quality — and groups findings by severity (critical, major, minor, nit). For every MAJOR or CRITICAL finding it adds a classification tag: RENDERED GAP (route to `image-prompt-editor`) or SPEC GAP (route to `image-prompt-writer`). It is strictly read-only and does not regenerate anything.

## Notes

- The agent emits a CONTEXT WRITE REQUEST block at the end of every invocation; the main agent must persist it.
- The overall verdict is PASS, PASS WITH NOTES, or REVISE; routing of findings is the main agent's responsibility, not the reviewer's.
