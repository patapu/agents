Invoke `reel-trend-verifier` as an OPTIONAL step between `reel-trend-scout` / `reel-news-scout` and `reel-hook-writer`. It is MANDATORY when either of these conditions is true: (a) the user or orchestrator explicitly requests claim verification before scripting, or (b) the CONCEPT BRIEF declares genre = `news` AND the briefing contains specific statistics, named numerical claims, or event-specific facts. Pass it either the explicit path to the briefing file OR the topic slug (e.g. `thai-news-2026-05-15`); the agent will Glob to locate the briefing from the slug. The agent cross-checks every factual claim in the TREND BRIEFING or NEWS BRIEFING against external sources (minimum 2 independent sources per claim), scores each claim using the versioned credibility-score schema (schema_version: 1), and persists a VERIFICATION REPORT to `research/<YYYY-MM-DD>/<slug>-verified.md` alongside the original briefing. The report contains per-claim blocks (fields: `claim_id`, `claim_text`, `score` 0–100, `label` HIGH/MEDIUM/LOW/UNVERIFIED, `evidence` list, `notes`), an Overall Trust block (`overall_score`, `confidence_label`, `recommendation` PROCEED/PROCEED-WITH-CAUTION/REJECT, `recommendation_notes`), and a Source Metadata table; `schema_version: 1` is a stable field that all downstream agents assert before consuming the report. The agent also returns a summary block to the caller (verification file path, overall score, confidence label, recommendation, per-claim summary). Writing the `-verified.md` file is mandatory — returning a summary without persisting the file is treated as a failure. The agent checks for a cached report before running (cache window: 24 h for news, 7 days for trends); on a cache hit it returns the cached report and writes no new files. Downstream behaviour when a `-verified.md` is present: `reel-hook-writer` refuses to write hooks on REJECT, prepends a CAUTION NOTICE on PROCEED-WITH-CAUTION, and never writes a hook whose premise rests on a LOW/UNVERIFIED claim; `reel-script-writer` refuses on REJECT, hedges MEDIUM claims with `รายงานว่า...`/`มีรายงานว่า...`, and forbids stating LOW/UNVERIFIED claim details as fact; `reel-production` automatically Globs the report on every review and raises CRITICAL/MAJOR findings for unhedged or rejected content (see reel-production SKILL.md for severity details). Do not use reel-trend-verifier to write scripts, hooks, captions, or hashtags — those belong to other agents.

## Notes

- The agent writes a context log to `.context/runs/{task_id}/agent-reel-trend-verifier.md` at the end of every invocation.
- If the schema version in a cached or found report does not match `schema_version: 1`, the agent stops and emits a `SCHEMA VERSION MISMATCH` error.
